2. Zero-shot, Few-shot, 단계적 추론 유도의 구분과 적용

   예시 없이 바로 시키면 항목별 분량이나 미확인 표기가 들쭉날쭉하더라고요.
   그래서 실제 후기 예시랑 '애매하면 되묻는 예시'를 Few-shot으로 넣고, 답변 전에 ① 모호함 확인 → ② 사실·미확인 구분 → ③ 4개 항목 작성 순서로 한 번 더 거치게 단계적 추론을 넣었어요.
